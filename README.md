# FortGate

保険代理店向け外部監査会社の会社案内サイトです。

## 目的
- 外部監査・内部統制／ガバナンス・各種フォローアップに関する信頼感のあるブランド表現
- スマホ対応の静的サイト
- Cloudflare Pages へのそのままデプロイ対応

## 主要ページ
- index.html
- company.html
- services.html
- message.html
- access.html
- contact.html

## スタイル
- 見出し: Manrope / Noto Sans JP
- 基本色: ネイビー + ゴールド
- 雰囲気: 信頼感 / 爽やか / 親しみやすさ

## デプロイ方法
1. GitHub にこのリポジトリを push
2. Cloudflare Dashboard > Pages > Create Project
3. GitHub から `FG-site` を選択
4. Production Build の設定を確認しデプロイ

## 補足
会社名、住所、メールアドレス、電話番号、代表者名などは仮入力です。正式情報が決まり次第差し替えできます。

- お問い合わせフォームは、ご担当者名・メールアドレス・お問い合わせ内容・プライバシーポリシーへの同意を必須とし、Formspree（`https://formspree.io/f/xoeeeolr`）へ POST 送信します。JavaScript 有効時はページ内に送信中・成功・失敗を表示し、成功後は入力内容を残して全フォーム操作を無効化・グレーアウトします。失敗時は入力内容を保持して再送信できます。無効化はそのページ内のみで、再読み込みや別タブからの送信まで制限するものではありません。JavaScript 無効時も通常のフォーム送信が可能です。迷惑送信対策として honeypot（`_gotcha`）を設けています。

- トップページ (`/index.html`) のPC向けGSAP演出は従来どおりです。760px以下ではWHY USを固定し、01・02・03をそれぞれ画面の高さ約1枚分の縦スクロール区間で表示します。区間の閾値を超えると480msで次のカードへ横スライドし、区間内ではカードを静止させます。03の区間が終わると固定を解除し、逆スクロールでも戻れます。短い画面では導入文を先に読み進め、カード全体が画面内に収まる位置で固定します。JavaScript無効時・`prefers-reduced-motion: reduce` 設定時は固定せず、通常の縦並びで全文を表示します。

### Formspreeの自動返信設定

自動返信はFormspree側で設定できますが、リポジトリの変更だけでは有効になりません。[公式資料](https://help.formspree.io/articles/plugins/sending-a-confirmation-or-response-email/)では **Professional / Business** プラン対象です。現在の契約プラン・有効化状況はこのリポジトリから確認できません。

1. Formspreeにログインし、送信先ID `xoeeeolr` のフォームを開きます。契約プランが自動返信に対応していることを確認します。
2. **Workflow** タブ → **Actions** の **+Add New** → **Auto Response** を選択します。
3. 送信者表示名（例：`FortGate`）、件名（例：`お問い合わせを受け付けました`）、本文を設定し、保存・有効化します。旧管理画面では **Plugins → Autoresponses** から設定します。
4. 本文は「お問い合わせありがとうございます。内容を確認のうえ担当者よりご連絡します。」などの固定文を推奨します。問い合わせ内容を返信本文に含める場合、公式資料ではカスタムドメインの追加が必要です。
5. 本番フォームから管理者自身が受信できるメールアドレスで1回送信し、管理者向け通知と送信者向け自動返信の両方を確認します。届かない場合は迷惑メールフォルダとFormspreeの送信履歴・設定を確認してください。

宛先の判定に必要なメール欄の `name="email"` は維持してください。APIキーやメール送信用の秘密情報をHTML・JavaScriptに追加する必要はありません。画面の「送信しました」はFormspreeでの受理を示し、自動返信メールの配達を保証する表示ではありません。未対応プランや自動返信未設定でも、お問い合わせ送信と担当者からの返信は従来どおり利用できます。

## トップページ操作確認（主要ブラウザ）
- 対象ブラウザ: 最新版 Chrome / Edge / Safari / Firefox（デスクトップ・モバイル）
- 760px以下ではWHY USが画面内に固定され、縦スクロールに連動して01→02→03が横に移動し、03の終端でAboutへ通常スクロールで進めること
- 各カードは閾値に達するまで静止し、閾値を超えると横スライドが完了すること。逆スクロールでも閾値を超えると03→02→01と戻ること
- 短い画面でもカード本文の末尾が隠れず、画面幅760pxと761pxをまたいだ際に固定・横移動・ARIA属性が正しく切り替わること
- PCでは既存のパネル切替・WHY USの01〜03切替が変わらないこと
- JavaScript無効時・`prefers-reduced-motion: reduce` では全カードを通常の縦並びで読めること
